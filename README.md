# Automation Script with Scheduling

A Python automation script that runs a recurring task automatically using the schedule library.

## Features

- Runs a task every 1 minute
- Records each execution in task_log.txt
- Displays execution status in the terminal
- Handles errors safely

## Run the Script

Activate the virtual environment and run:

python automation.py

## Scheduling

The script uses the Python `schedule` library to run the task every minute.
